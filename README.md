# Console-Based Banking System (Java)

A simple console-based banking system developed in Java. This project simulates core banking functionalities such as account creation, deposit, withdrawal, and balance inquiry, all through a text-based interface.

## Features for admin

1. Exit/Logout
2. Create a customer account
3. See all transactions
4. Check bank balance
5. Approve cheque book request

## Features for users

 1. Exit/Logout
 2. Check bank balance
 3. Fund transfer
 4. See all transactions
 5. Raise a cheque book request
 6. Simple data handling using in-memory storage (no database)
 7. Console-based user interaction

## Technologies Used

- Java (JDK 7 or higher)
- No external libraries or frameworks

### Prerequisites

To run this application, you need to have the following installed on your system:

- Java Development Kit (JDK 7 or higher)
- IntelliJ IDEA or any Java IDE
- Git (to clone the repository)

### How to Access and Run the Application

1. **Clone the Repository**
  
   ```bash
 git clone https://github.com/your-username/your-repo-name.git
 cd your-repo-name

2. **Open the IntelliJ IDEA**

- Open IntelliJ IDEA.
- Click on File> Open and select the cloned project directory.

3. **Run the Application**

- Navigate to the **main** class( typically **Main.java**).
- Right-click on the file and select **Run**.
- The console interface will appear in the terminal.

4. **Use the Application**

- Follow the on-screen prompts to create accounts, deposit money, withdraw money, and check balances.
